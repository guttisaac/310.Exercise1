# DSDA 310: Project 1 Proposal

## Objective

Predict whether income exceeds $50K/yr based on census data.

## Dataset

The dataset includes the following variables:

- Age
- Workclass
- Fnlwgt
- Education
- Education-num
- Marital Status
- Occupation
- Relationship
- Race
- Sex

The dataset has 48,000 distinct entries and is already split roughly 32,000 / 16,000 between **Train** and **Test** sets.

## Goal

The goal is to create a model that can accurately predict whether a person, based on the attributes in the dataset, makes over or under $50K a year.

## Methodology

- Use a **Scikit-Learn** model.
- Evaluate performance using the following metrics:
  - Accuracy
  - Precision
  - F1 Score
  - Recall
- Delete any contaminated data

## Baseline Comparison

The model will be compared against a baseline of a random guess, which should be correct about half the time.
