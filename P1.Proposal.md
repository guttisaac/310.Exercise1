# DSDA 310: Project 1 Proposal

## Objective

Predict whether an individuals income exceeds $50K/yr based on census data.

## Dataset

The dataset includes the following variables:

- Age
- Workclass
- Final Weight
- Education
- Education Years
- Marital Status
- Occupation
- Relationship
- Race
- Sex

The dataset has 48,000 distinct entries and is already split roughly 32,000 / 16,000 between **Train** and **Test** sets.

## Goal

The goal is to create a model that can accurately predict whether a person, based on the attributes in the dataset, makes over or under $50K a year.

## Methodology

- Use a logistical regression model.
- Evaluate performance using the following metrics:
  - Accuracy
  - Precision
  - F1 Score
  - Recall

## Data Leakages
- No major leakages are initially seen in the dataset
- ? values were in the dataset, primarily in the workclass column, these were changed to null vaules

## Baseline Comparison

- The baseline model is a simple linear regression model:
Test Accuracy: 0.84
Test Precision: 0.73
Test Recall: 0.60
Test F1-score: 0.66
